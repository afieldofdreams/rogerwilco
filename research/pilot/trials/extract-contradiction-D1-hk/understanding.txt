The task requires extracting supplier invoices from an August 2026 email thread into a structured JSON array. Key requirements: (1) include all invoices from all suppliers across all currencies, with each currency recorded in ISO 4217 format; (2) report net amounts (excluding VAT) in the amount field; (3) include VAT as a separate number field, or null if not applicable; (4) use ISO 8601 date format (YYYY-MM-DD) for both invoice date and due date; (5) preserve invoice numbers exactly as written, including prefixes and leading zeros; (6) exclude voided/cancelled invoices, credit notes, and account statements; (7) output as a single JSON array with no prose or code fences. Acceptance criteria: accurate data extraction, correct date parsing, proper VAT separation, and complete exclusion of non-invoice documents.
