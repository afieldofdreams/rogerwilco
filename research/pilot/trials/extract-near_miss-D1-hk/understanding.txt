The task requires extracting supplier invoices from an email thread into a JSON array with specific fields: supplier name, invoice number (as written), ISO 8601 date, gross amount including VAT, ISO 4217 currency code, VAT amount, and due date. Only GBP invoices are included; USD invoices are excluded. Voided invoices, credit notes, and statements are excluded. Invoice numbers must preserve exact formatting including leading zeros and prefixes. Amounts in the JSON should be the gross total including VAT. Due dates are calculated from payment terms or set to null if not specified. The output is a single JSON array with no additional prose or code fences. The correction email updates INV-000491 figures and supersedes the original amounts.
