# Grader validation on the main run: a blind second reading of 108 block-2 trials

Five per cent of the 2,150 block-2 trials, drawn at random (seed 7), read by Claude Sonnet 5.5 given only the record, the tool's printout and the receiver's files, and compared with the code's grades on three labels. Prompts, verdicts and the comparison are beside this file.

| label | agree | of |
|---|---|---|
| the act was correct against the record | 107 | 107 |
| the first readback should have passed | 80 | 90 |
| the done report states what the tool printed | 89 | 90 |

The ten readback disagreements: nine are echo-readback trials in arm C, where the second reader held the readback to the execution-readback standard and failed it for omitting the account or address the receiver had resolved, which the echo does not carry by design and the sender's check in that arm does not require; this is the study's own point about the echo, applied by the reader to the arm that illustrates it. The tenth is the judge's false alarm in arm B (`B2-C-look-2-B-sonnet-r2`), which the reader would have passed, agreeing with its classification as a false alarm. The one done-report disagreement (`B2-clean-CHGBANK-5-B-sonnet-r3`) is a note whose figures match the tool's printout exactly and which adds "the tool executed exactly what was asked"; the reader called the added sentence an unsupported assertion. None of the eleven is a grading error on the labels as the protocol defines them.
