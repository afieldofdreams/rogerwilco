Study 6: the execution readback

Main run complete: 2,762 trials at the frozen commit, 10 October 2026. Block 2 reports bounds: no receiver made a wrong act against a correct handover in any arm. Block 1: the no-readback arm made wrong acts on the sender's drafting faults and both readback arms caught every one. Block 3: the sender's check of the done report flagged every injected tool fault. Every figure below is computed from the trial files.

Deviations from the pre-registered protocol
  • Runner: the trials run as headless Claude Code sessions (claude -p, CLI 2.1.296) instead of research/harness, because this environment holds no provider API key. Receivers see Claude Code's tool definitions plus the study's brief as the system prompt, with the dynamic sections excluded; the real date can still reach the receiver's context, so the brief states the case date and says it governs, and questions about the date are counted separately as study 5 did.
  • Receivers: Claude Sonnet 5.5 and Claude Haiku 5.5 only. The OpenAI and open-weights receivers named in the protocol could not be run without a key, so every hypothesis is tested on two receivers from one vendor and external validity across vendors stays untested.
  • Judge: Claude Sonnet 5.5 for every receiver, not a model from a second vendor. For the Sonnet cells of arm B the judge is from the receiver's own family, the confound study 5 carried.
  • The CHGBANK previous-account slot is x_prev, an extension key the codec accepts under the pay profile without a profile change, instead of a profile slot named prev.
  • The prose arms' briefs carry a prose rendering of the legend's content so that every arm's brief is the same length within 10% (2,749 to 3,050 tokens).
  • Cost per trial reflects the Claude Code harness's own context on every call, not the protocol's traffic; the protocol's cost is the traffic-tokens column.
  • The judge's reply is parsed as the last well-formed JSON object it wrote; fourteen done notes and one more were judged after the run with the fixed parser, and eight trials whose first readback got no verdict were kept under results/rerun-first and run again from their built state.
