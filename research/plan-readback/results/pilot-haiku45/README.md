# Exploratory probe: Claude Haiku 4.5 as the no-readback receiver on block 2, level 0

Not part of the pre-registered design. After the ladder produced no wrong act on either registered receiver, the weakest Claude receiver available in this environment, Claude Haiku 4.5 (claude-haiku-4-5-20251001), was run on the 43 block-2 handovers at level 0 in arm A, two repeats, 86 trials (ids end in `-x`). Purpose: to learn whether any Claude receiver to hand makes the receiver-side errors block 2 was built to induce, before deciding whether block 2 can carry its hypotheses.

Result: no wrong act in 56 induced trials and none in 30 clean ones; it asked twice (both on the lookalike-domain email giving new bank details) and acted correctly otherwise. Cost $0.05 a trial.
